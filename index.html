Demo

Live demos of ScalpelSpace hardware, running in the browser over a USB serial connection. Connect a board and the page asks it what it is, then loads that product's demo. Nothing is installed and no data leaves the machine.

This browser cannot talk to serial devices. The demos need the Web Serial API. Use desktop Chrome, Edge or Opera over https:// or http://localhost. Everything below still renders so you can see what the page does, only connecting to hardware is unavailable.
The page did not start. It loaded but its code did not run, which usually means this browser is too old for it. Try the current version of Chrome or Edge on a desktop.

Boot control lines

      

        A ScalpelSpace board wires DTR to BOOT0 and RTS to NRESET so it can be
        flashed hands free. That also means opening a port asserts BOOT0 and
        starts the bootloader, which answers no commands, so the page releases
        the lines and resets into the application on connect. Change these
        only for a board that maps or inverts them differently.
